# Module 12: Reference and Codeforces Catalog Guide

The [Codeforces Catalog](https://codeforces.com/catalog) is a community-curated repository containing the most influential tutorials, blogs, and techniques written by world-class competitors, including International Grandmasters, IOI medalists, and Codeforces problemsetters.

In this directory, you will find:
- **[[12_Reference_and_Catalog/codeforces_catalog_full.md|codeforces_catalog_full.md]]:** The complete index of all **388+ catalog blog posts**, categorized by topic with direct links and descriptions.

---

## 🌟 The Essential "Must-Read" List for Beginners

If you are starting competitive programming with Python, prioritize these foundational articles in order:

### 1. General Advice & Practice Methodology
1. **[How to use Codeforces [GUIDE]](https://codeforces.com/blog/entry/99660)** by *SlavicG*
   - Explains the rating system, round structure, problem navigation, and tags.
2. **[How to read problem statements](https://codeforces.com/blog/entry/62730)** by *Um_nik*
   - Essential advice on extracting the core mathematical abstraction from story-driven problem statements.
3. **[A way to Practice Competitive Programming : From Rating 1000 to 2400+](https://codeforces.com/blog/entry/66909)** by *E869120*
   - A structured step-by-step training curriculum that took an author to Red level.
4. **[My opinion on how to practice competitive programming](https://codeforces.com/blog/entry/91114)** by *Radewoosh*
   - Practical, unvarnished guidance on contest preparation and deliberate problem solving.

### 2. Algorithmic Thinking & Solution Techniques
1. **[How to come up with the solutions: techniques](https://codeforces.com/blog/entry/20548)** by *MikeMirzayanov*
   - Techniques for generating ideas when you are stuck.
2. **[Characteristics of the optimal solution](https://codeforces.com/blog/entry/99291)** by *Proofy*
   - Finding invariants and extremal properties.
3. **[On "is this greedy or DP", forcing and rubber bands](https://codeforces.com/blog/entry/106346)** by *-is-this-fft-*
   - Crystal clear mental distinction between greedy choices and DP state spaces.

### 3. Core Algorithm Deep Dives
1. **[EDU: Binary Search](https://codeforces.com/blog/entry/67568)** by *pashka*
2. **[EDU: Two Pointers Method](https://codeforces.com/blog/entry/78586)** by *pashka*
3. **[EDU: Disjoint Set Union](https://codeforces.com/blog/entry/75428)** by *Aksenov239*
4. **[EDU: Segment Tree, part 1](https://codeforces.com/blog/entry/78762)** by *pashka*
5. **[Dp On Trees](https://codeforces.com/blog/entry/63257)** by *AghaTizi*
